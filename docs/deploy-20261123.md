# November 23 combined release

Merge upstream `01d6ce9` and illustrated rewards PR #180 (`1c6647f`)
into the existing deployment branch. Retain its protocol and dependency patches.
Farm illustrated rewards have an independent account setting and persistent pending
protection. Upstream ranch illustrated rewards retain their separate setting.

Build on Linux01 using a dedicated BuildKit limited to two CPUs and 4 GiB.
Use the existing pinned Node 20.19.6 Alpine amd64 base. Export the image locally,
copy to the authorized NAS SMB artifact directory and compare SHA-256 after reading it back.
Keep the previous runtime image and a private consistent snapshot of the stopped
Linux02 data, logs and configuration. Never put account or administrator data on SMB.

Publish the committed image reference using the scoped ops item
`system/linux02-qq-farm-bot`. Load the verified image on Linux02, then use
`python3 deploy/deploy.py check --image TAG`, `apply --image TAG`, and `check --image TAG`.
The deploy script only activates the existing Compose service; it never changes
configuration, the proxy, account credentials, or account start state.

Verify version and home routes, image identity, health, account/config preservation,
and recovery after a container restart. No whole-host reboot is part of this release.
On failure, stop the new writer and restore the previous image through ops and this
deploy script. Restore the private data snapshot only when necessary for compatibility,
preserving any new state first. Do not replay a game Code or automatically log in.
